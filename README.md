# PB Gen - Americano Pickleball Tournament Generator

A sophisticated iOS app built with SwiftUI that generates fair, balanced match schedules for americano-style pickleball tournaments where players rotate partners and opponents to ensure equitable play distribution.

## Overview

**Americano Format**: A tournament style where players rotate partners each round, face different opponents, and rankings are based on individual wins and point differentials rather than fixed team performance.

### Key Features
- 🎯 Fair scheduling algorithm with sophisticated partner/opponent rotation
- 📱 Native iOS app built with SwiftUI and MVVM architecture
- 💾 Multi-tournament management with persistent storage
- 📊 Real-time leaderboard with multiple sorting options
- ➕ Dynamic round addition during tournaments
- 🎮 Score tracking with point differential calculations
- 👥 Intelligent rest player management for odd numbers
- ✅ Comprehensive validation and error handling
